# 백엔드 통합 API 및 데이터 관리 서비스 개발

**기술 Stack**: Java, Spring, Netty, TCP Custom Binary Protocol, REST API, JSON
**소속**: Tmax Tibero · 데이터 동기화 엔진팀

## 개요 (Overview)

데이터 동기화 엔진을 상위 관리도구 및 상태 제어 대시보드와 유기적으로 결합하기 위한 고성능 백엔드 API 레이어를 설계하고 구현하였습니다. 기존 분산 동기화 엔진 내부에 설계되어 있던 고유의 통신 프로토콜을 백엔드 단에서 효율적으로 재사용하기 위해, Java Spring 및 Netty 기술을 융합하여 커스텀 통신 파이프라인을 구축하였습니다. 이를 통해 운영 제어용 REST API뿐만 아니라, 자체 바이너리 프로토콜을 투명하게 직렬화/역직렬화(Serializer/Deserializer) 처리하는 통신 어댑터를 직접 개발하여 저비용·고성능 통합 인터페이스를 완결지었습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **Netty 기반의 고성능 소켓 서버 및 프로토콜 어댑터 설계**: 동기화 엔진이 사용하는 바이너리 데이터 메시지를 고속으로 변환하고 해석하기 위해 Netty 프레임워크 기반의 비동기 소켓 통신 모듈을 구축하였습니다. 바이너리 스트림 데이터에 대한 직렬화 및 역직렬화 메커니즘을 어댑터 패턴으로 구조화함으로써, 기존 가용 스펙을 유지하면서 가볍고 기민한 고효율 RPC(Remote Procedure Call) 연동 아키텍처를 확보하였습니다.
- **클라이언트 사이드 렌더링(CSR)용 JSON API 설계**: 웹 관리 인터페이스(대시보드 UI)가 동기화 상태를 모니터링하고 가시화할 수 있도록 안정적이고 표준화된 RESTful API 구조를 정의하였습니다. 데이터 정합성 검사, 대량 데이터 복사 및 초기 적재(ETL)와 같은 고성능 핵심 관리 기능들을 손쉽게 원격 제어할 수 있는 API 제어 인터페이스 체계를 마련하였습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **안정적 모니터링 시스템 구축 및 연동 성능 보장**: 직관적이고 고신뢰성을 지닌 제어 API 설계를 전담하여 외부 운영 환경과 코어 엔진의 통신 신뢰도를 극대화하였으며, 이를 통해 대형 시스템 연동 비용을 크게 절감하였습니다.
- **이기종 분산 데이터 허브의 초석 마련**: 정적 수동 복제 방식에 국한되어 있던 인프라 관리를 온디맨드(On-demand) 제어가 가능한 실시간 REST API 서비스 형태로 전환시킴으로써 동기화 솔루션의 소프트웨어 가치를 제고하였습니다.
