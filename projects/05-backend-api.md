# 백엔드 통합 API 및 데이터 관리 서비스 개발

**기술 Stack**: Java, Spring, Netty, TCP Custom Binary Protocol, REST API, JSON
**소속**: Tmax Tibero · 데이터 동기화 엔진팀

## 개요 (Overview)

데이터 동기화 엔진을 대시보드 및 운영 도구와 연동하기 위해 고성능 백엔드 API 레이어를 설계하고 개발했습니다. 동기화 엔진의 독자적인 C 기반 통신 프로토콜을 자바 백엔드 단에서 처리할 수 있도록, Spring과 Netty를 활용해 커스텀 소켓 파이프라인을 구축했습니다. 이를 통해 운영 제어용 REST API를 제공하는 한편, 자체 바이너리 프로토콜을 직렬화/역직렬화(Serializer/Deserializer) 처리하는 어댑터를 설계하여 신속한 통합 인터페이스를 구축했습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **Netty 기반 바이너리 프로토콜 어댑터 설계**: 동기화 엔진이 사용하는 바이너리 메시지 형식을 신속하게 파싱하고 전송하기 위해 Netty 기반의 비동기 소켓 통신 모듈을 구축했습니다. 바이너리 스트림 데이터를 어댑터 패턴으로 구조화하여 해석함으로써, 별도의 프로토콜 변경 없이도 기존 통신 스펙을 그대로 재사용하는 경량 RPC(Remote Procedure Call) 연동 구조를 확보했습니다.
- **CSR(Client-Side Rendering) 대시보드용 JSON API 설계**: 웹 관리 인터페이스에서 엔진의 동기화 상태를 모니터링하고 제어할 수 있도록 RESTful API를 설계했습니다. 데이터 정합성 검사, 대용량 초기 적재(ETL) 등 자원이 많이 소모되는 핵심 기능을 웹 UI 상에서 안전하게 원격 호출하고 제어할 수 있도록 API 구조를 마련했습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **통합 API 설계를 통한 관리 효율화**: 제어 및 모니터링용 API 설계를 담당하여 관리 도구와 코어 엔진 간의 통신 신뢰도를 확보하고 상용 환경에서의 오동작 가능성을 예방했습니다.
- **온디맨드 관리 서비스화**: 수동 터미널 작업에 의존하던 제어 구조를 실시간 REST API 서비스 형태로 추상화하여, 통합 관리가 가능한 솔루션 제품군으로의 서비스 확장에 기여했습니다.
