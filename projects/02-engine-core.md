# 동기화 엔진 코어 프레임워크 유지보수 및 개선

**기술 Stack**: C, POSIX System Call, epoll, mmap
**소속**: Tmax Tibero · 데이터 동기화 엔진팀

## 개요 (Overview)

AIX, HP-UX, Solaris, Linux 등 이기종 OS 환경에서 작동하는 데이터베이스 동기화 엔진 코어를 담당하여, 플랫폼 다변화 환경에서도 일관된 네트워크 및 메모리 제어가 가능하도록 프레임워크를 개선했습니다. dlmalloc 기반의 자체 사용자 레벨 메모리 할당자(`prs_malloc`)를 관리하며 컴포넌트별 메모리 추적 로깅을 강화했고, 대량 소켓 처리를 위해 non-blocking 소켓 구조를 연동했습니다. 아울러 예외적인 네트워크 연결 유실 상황에서 발생하는 커널 및 소켓 리소스 누수(epoll stale) 문제를 해결하여 엔진의 장기 구동 안정성을 높였습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **이기종 OS 메모리 사용 추적 및 일관성 보장**: `mmap` 시스템 콜 기반으로 대역 메모리를 미리 점유하여 사용자 레벨에서 분할 관리하는 `dlmalloc` 기반 `prs_malloc` 할당자를 유지보수했습니다. 이를 통해 플랫폼마다 상이한 동적 메모리 할당 정책을 통일해 일관성을 유지하고, 프로세스 단위 로그의 한계를 극복하여 컴포넌트 단위 메모리 사용량 실시간 관측 인프라를 마련했습니다.
- **Non-blocking 소켓 연동을 통한 I/O 처리율 개선**: 기존 I/O Multiplexing 구조를 최적화하기 위해, non-blocking 소켓을 신규 도입하여 동시성 상황에서의 소켓 블로킹 오버헤드를 제어했습니다.
- **네트워크 단선 시 epoll 커널 리소스 누수 해결**: 하드웨어 단선이나 비정상 소켓 중단 시, 커널 epoll 이벤트 리스트에 등록된 stale 소켓 자원이 해제되지 않는 문제를 조사했습니다. OS 커널 및 TCP Keep-Alive timeout 스펙을 고려한 자동 리소스 회수 로직을 직접 구현해 메모리 및 커널 디스크립터 누수를 통제했습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **엔진 진단 신뢰성 확보**: 이기종 상용 고객사 환경에서 일관된 메모리 할당 정책을 보장하고 정밀한 모듈별 실시간 메모리 상태 관측 로그를 제공함으로써 기술 지원 및 리포팅 정밀도를 크게 향상시켰습니다.
- **커널 자원 안정성 입증**: 비정상 단선 시 고질적으로 발생할 수 있는 시스템 누수 상황을 예방하고, 지속적으로 구동해야 하는 상용 인프라 소프트웨어의 신뢰성을 입증했습니다.
