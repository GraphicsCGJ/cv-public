# 동기화 엔진 코어 프레임워크 유지보수 및 개선

**기술 Stack**: C, POSIX System Call, epoll, mmap
**소속**: Tmax Tibero · 데이터 동기화 엔진팀

## 개요 (Overview)

이기종 OS(AIX, HP-UX, Solaris, Linux) 환경에서 작동하는 상용 데이터베이스 동기화 엔진 코어를 전담하여, 다양한 플랫폼 환경에서 일관적이고 예측 및 추적 가능한 메모리와 네트워크 동작을 보장하도록 프레임워크를 개선하였습니다. dlmalloc 기반의 자체 사용자 레벨 메모리 할당자(`prs_malloc`)를 유지보수하고 컴포넌트별 메모리 사용량 추적 모니터링을 강화하였으며, 고성능 네트워크 처리를 위해 non-blocking 소켓을 연동하였습니다. 또한, 예외적인 네트워크 단선 상황에서 발생하던 리소스 누수(epoll stale)를 정리할 수 있는 자원 수거 로직을 구현하여 제품의 신뢰성과 운영 안정성을 대폭 제고하였습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **크로스 플랫폼 메모리 가시성 및 일관성 확보**: `mmap` 시스템 콜을 활용해 대량의 메모리 영역을 선점한 뒤 사용자 레벨에서 여유 공간을 관리하는 `dlmalloc` 기반의 `prs_malloc` 할당자를 유지보수하였습니다. 이를 통해 이기종 운영체제(AIX, HP-UX, Solaris, Linux) 간 일치된 동적 할당 메커니즘을 보장하고, 기존 프로세스 단위의 투박한 모니터링(예: `mallinfo`) 한계를 극복하여 컴포넌트별 실시간 메모리 사용량 추적 및 디버깅 로그를 구현하였습니다.
- **네트워크 비동기 입출력 고도화**: 초기 동기화 엔진에 분산되어 있던 I/O Multiplexing 구조를 최적화하기 위해, Non-blocking 소켓 연동 아키텍처를 도입하여 I/O 블로킹 오버헤드를 줄이고 동시 처리 효율을 향상시켰습니다.
- **예외적 연결 종료 시 epoll 리소스 정리**: 물리적 네트워크 단선(예: 랜선 뽑힘, 비정상 소켓 중단 등) 시 epoll 리스트에 등록된 커널 자원이 정상적으로 해제되지 않아 누적되는 현상을 해결하였습니다. OS 커널 및 TCP Keep-Alive timeout 스펙을 세밀히 통합 제어하여, 장기 가동 시 발생할 수 있는 커널 자원 누수(leaks)를 완전히 통제하고 장기 운영 안정성을 강화하였습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **엔진 안정성 및 디버깅 편의성 획기적 개선**: 다양한 상용 아키텍처 및 OS 고객사 환경에서 균일한 메모리 할당 패턴을 보장하고, 정확한 소스 컴포넌트 단위 메모리 추적 데이터를 확보하여 고객 기술 리포팅 업무 효율을 극대화하였습니다.
- **저수준 리소스 누수 근절**: 비정상 단선 시 고질적으로 발생하던 소켓 및 커널 epoll 이벤트 디스크립터 누수를 근본적으로 해결함으로써 시스템 무중단 보장 성능을 향상시켰습니다.
