# 이기종 하드웨어 및 소프트웨어 통합 검증 테스트 자동화 플랫폼

**기술 Stack**: Python, Apache Airflow, Git, JFrog, DuckDB, Apache Parquet, Grafana, Sentry, Slack, fio, iperf, perftest
**소속**: MangoBoost · Software Engineering Group

## 개요 (Overview)

신규 하드웨어(FPGA, ASIC) 및 소프트웨어(디바이스 드라이버, 펌웨어) 개발 사이클에서 수동 실행 및 단순 PR(Pull Request) 기반 검증 방식이 가졌던 시계열 성능 지표의 누락 문제와 정량적 검증 한계를 혁신하기 위해 통합 테스트 자동화 플랫폼을 구축하였습니다. 빌드 감지부터 릴리즈 아티팩트 배포, 매일 수행되는 데일리 회귀(Daily Regression) 테스트 파이프라인을 구축하였으며, 하드웨어 특화 벤치마크 워크로드(fio, iperf, perftest)의 전 과정을 자동화하였습니다. 테스트 결과 데이터를 고성능 컬럼형(Columnar) 데이터 저장 포맷으로 지속 축적하고 모니터링 체계를 갖춤으로써, 시스템 버그와 실시간 성능 저하(Regression) 유무를 자동으로 모니터링하는 인프라를 완성하였습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **스케줄 기반의 데일리 회귀(Daily Regression) 테스트 자동화**: Apache Airflow 및 JFrog 아티팩트 관리 솔루션을 연계하여, 일일 주기 단위의 테스트 빌드 다운로드 및 타겟 장비 프로비저닝 자동화 흐름을 확보하였습니다. 1회성 PR 트리거링 테스트에서 시계열 중심의 장기 운영 회귀성 테스트 구조로 전환함으로써 장기 수명 안정성을 확보하였습니다.
- **하드웨어 및 네트워크 벤치마크 파이프라인 구축**: 가상 및 물리 장비 위에서 블록 스토리지 워크로드(`fio`), 네트워크 가용 대역폭(`iperf`), 저지연 성능 지표(`perftest`) 등의 필수 저수준 부하 테스트 실행을 완전히 자동화하고 통합 제어 환경을 구성하였습니다.
- **분석용 데이터 파이프라인 설계 및 다차원 성능 가시화**:
  - **초고속 분석 전용 스토리지 설계**: 누적되는 성능 원시 로그를 디스크 및 네트워크 비용이 최적화된 Columnar 포맷인 Apache Parquet 구조로 연속 직렬화하여 축적하였습니다.
  - **초경량 임베디드 쿼리 엔진 연동**: DuckDB 쿼리 인터페이스를 통합하여 대규모 수동 분석 없이 수억 건의 누적 벤치마크 데이터 속에서 버전별 고유 성능 차이를 즉각적으로 질의하고, 이를 Grafana 대시보드와 통합 시각화하여 미세한 수치 변화까지 감지할 수 있도록 구현하였습니다.
- **실시간 장애 인지 및 관측 가능성(Observability) 제공**: 검증 도중 발생하는 펌웨어 커널 패닉 및 디바이스 에러에 대한 시스템 추적을 수동 로그 분석 대신 Sentry 에러 트래킹 엔진 및 Slack 연계 채널로 자동 전환하여 디버깅 주기를 단축시켰습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **정량적·지속적 비교 검증 인프라 확보**: 자사 SmartNIC 제품군과 타 제품군 간의 정교한 장기 비교 분석 지표를 일원화 및 정량화하여 제품의 가치를 입증하는 데 기여하였습니다.
- **장애 인지 속도 개선 및 효율화**: 수동 로그 검색 업무를 시각적 대시보드 모니터링과 자동 푸시 경보 시스템으로 완벽히 전환하여, 신규 개발 코드의 비정상 장애 유입 시 즉시적인 원인파악이 가능한 환경을 제공하였습니다.
