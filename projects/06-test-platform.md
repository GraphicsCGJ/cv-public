# 이기종 하드웨어 및 소프트웨어 통합 검증 테스트 자동화 플랫폼

**기술 Stack**: Python, Apache Airflow, Git, JFrog, DuckDB, Apache Parquet, Grafana, Sentry, Slack, fio, iperf, perftest
**소속**: MangoBoost · Software Engineering Group

## 개요 (Overview)

신규 하드웨어(FPGA, ASIC) 및 시스템 소프트웨어(디바이스 드라이버, 펌웨어) 개발 사이클에서 수동 실행 및 단순 PR(Pull Request) 트리거 방식의 테스트가 가졌던 정량적 지표 누락 문제를 극복하고자 일일 테스트 자동화 플랫폼을 구축했습니다. 빌드 감지부터 배포, 일일 회귀(Daily Regression) 테스트 실행에 이르는 전 과정을 Airflow로 자동화하였고, 하드웨어 성능 측정을 위한 벤치마크 툴(fio, iperf, perftest)들을 통합 제어했습니다. 테스트 결과 데이터를 컬럼형(Columnar) 데이터 포맷으로 축적하고 모니터링 체계를 연동하여 버그와 성능 저하를 지속 추적할 수 있도록 했습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **스케줄 기반 일일 회귀(Daily Regression) 테스트 자동화**: Apache Airflow 및 JFrog 아티팩트 저장소를 연계해 일일 단위로 최신 테스트 빌드를 다운로드하고 타겟 서버 장비를 프로비저닝하는 자동화 파이프라인을 구축했습니다. 단발성 PR 테스트 외에, 누적 시계열 지표 확보를 위한 장기 회귀 테스트 환경을 정비했습니다.
- **하드웨어 및 네트워크 벤치마크 연동**: 가상 및 물리 서버 상에서 디스크 I/O 성능(`fio`), 네트워크 가용 대역폭(`iperf`), 저지연 데이터 전송 지표(`perftest`) 등 저수준 시스템 부하 테스트 실행을 자동화하고 통합 웹 UI에서 모니터링할 수 있도록 구현했습니다.
- **분석용 데이터 파이프라인 설계 및 다차원 성능 시각화**:
  - **시계열 성능 데이터 직렬화 및 축적**: 수 기가바이트 단위로 누적되는 원시 테스트 로그 파일들을 디스크 효율성과 속도가 뛰어난 Apache Parquet 포맷으로 가공해 축적했습니다.
  - **DuckDB 및 Grafana 연동을 통한 성능 분석**: 분석 쿼리용 경량 엔진인 DuckDB 인터페이스를 연동해 대용량 벤치마크 원시 로그 내에서 버전별 성능 차이를 즉각 비교할 수 있도록 처리하고, Grafana 대시보드 상에서 비교 분석 결과를 직관적으로 관찰하게 했습니다.
- **장애 모니터링 및 즉시 전파**: 테스트 수행 과정에서 발생하는 펌웨어 커널 패닉이나 디바이스 에러에 대해, 수동 로그 분석 대신 Sentry와 Slack을 연동하여 시스템 오류가 즉각 전파되도록 개선하고 디버깅 효율을 높였습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **장기적인 정량 비교 분석 지표 마련**: 자사 SmartNIC 제품군과 타사 제품군 간의 정밀한 장기 비교 벤치마크 데이터를 정량적으로 일원화해 제품 신뢰성 제고에 기여했습니다.
- **수동 공수 절감 및 장애 전파 속도 단축**: 기존의 수동 로그 파일 확인 공수를 시각적 모니터링 대시보드와 푸시 경보 시스템으로 개선하여 장애 상황 대응 효율을 향상시켰습니다.
