# Tibero GIS 공간 데이터 처리 라이브러리 모듈화 및 개발

**기술 Stack**: C++, C, WKB, 자체 Memory Allocator, PostGIS/Oracle Spatial 호환
**소속**: Tmax Tibero · GIS 엔진팀 (2023.01–06)

## 개요 (Overview)

기존 C 엔진 내부에 인라인 형태로 분산되어 장기간 관리되어 온 GIS 기능을 유지보수와 확장이 용이한 구조로 개선하기 위해 독립적인 라이브러리로 분리하고 모듈화하는 작업을 추진하였습니다. GIS 데이터 처리를 C++ 기반의 라이브러리 및 프레임워크로 이식하여 체계적으로 구조화하는 과정에 참여하였으며, 특히 자체 할당자 기반의 GIS 메모리 처리 엔진(vec2/3/4 좌표 차원 대응)과 주요 공간함수(ST_ 계열)의 설계를 직접 담당하여 Tibero 7에서의 다각적인 공간 데이터 확장 토대를 마련하였습니다.

## 주요 아키텍처 및 해결 과제 (Key Architecture & Technical Challenges)

- **레거시 코드의 모듈화 및 이식**: 기존 C 엔진 내의 인라인 코드를 정제하여 독립적인 C++ 라이브러리 체계로 이식 및 모듈화하였습니다. 이를 통해 GIS 기능의 높은 응집도와 낮은 결합도를 실현하여 향후 유지보수와 기능 확장성을 획기적으로 개선하였습니다.
- **다차원 좌표 데이터 처리 최적화**: 2차원 공간 좌표(XY)뿐만 아니라 고도(Z), 선형 참조(M) 정보가 포함된 3차원 및 4차원 좌표 차원(vec2/vec3/vec4)에 대응할 수 있도록 구조화하였습니다. WKB(Well-Known Binary) 표준 포맷과의 호환성을 갖추어 공간 데이터 인프라의 표준 사양을 엄격히 준수하였습니다.
- **공간 데이터 전용 자체 메모리 할당 설계**: GIS 연산의 대용량 데이터 특성을 고려하여 성능과 가비지 관리 성능을 개선하기 위해 전용 메모리 할당자(Memory Allocator)를 연동하였습니다. 이를 통해 잦은 메모리 할당/해제 오버헤드를 제어하고 메모리 누수를 원천 차단하였습니다.

## 기여도 및 주요 성과 (Contributions & Achievements)

- **공간 데이터 연산 인프라 토대 확립**: 모듈화 작업 완수를 통해 Tibero 7 버전에서 대대적인 공간함수 기능 고도화의 기틀을 확립하였습니다. (Tibero 6 버전의 ST_ 함수 63개 대비 Tibero 7.2.5 버전에서 80개 이상으로 확장)
- **독립 모듈 설계 기여**: GIS 메모리 처리 아키텍처 및 다차원 분기 설계, 그리고 일부 핵심 ST_ 공간 함수들의 효율적인 이식과 검증을 전담 수행하여 라이브러리의 전체적인 완성도를 제고하였습니다.
