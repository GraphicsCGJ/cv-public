# Tibero GIS 공간 데이터 처리 라이브러리 모듈화·개발

기술: C++, C, WKB, 자체 Memory Allocator, PostGIS/Oracle Spatial 호환
소속: Tmax Tibero · GIS 엔진팀 (2023.01–06)

## 330자판 (330자)

```
[목표/배경]
기존 C 엔진에 인라인으로 흩어져 오래 관리돼 온 GIS 기능을, 독립 라이브러리로 분리해 유지보수·확장 가능한 모듈로 만들 필요가 있었습니다.
[역할·수행]
GIS 데이터 처리를 C++ 라이브러리/프레임워크로 이식·구조화하는 작업에 참여했고, 그중 GIS 메모리 처리(자체 할당자 기반, vec2/3/4 좌표 차원 대응)와 일부 공간함수(ST_ 계열) 구현을 담당했습니다.
[성과·기여도]
GIS를 독립 모듈로 관리할 기반을 마련해, Tibero 7에서 다수 공간함수 추가·확장 토대가 됐습니다. (개인 기여도 약 20% — 후반부 합류, GIS 메모리·일부 ST_ 함수)
```

## 핵심 스토리 (성능 아님 — 아키텍처)

- **가치 = 성능 배수 아님.** 레거시 인라인 GIS 코드 → 독립 C++ 라이브러리/프레임워크로 **이식·모듈화** → 이후 확장 가능해진 것.
- **증거**: v6(2015) ST_ 함수 63개 → v7.2.5 80+ (약 35개 추가). 모듈화 기반이 있었기에 대량 확장이 가능. (버전 diff는 gis_misc.md 참고)
- 억지 성능 수치 넣지 말 것.

## 내 개인 기여 (정직 스코핑)

- 담당: **GIS 메모리 처리**(자체 allocator 기반, vec2/3/4 = XY/XYZ/XYZM 차원 분기) + **일부 ST_ 공간함수 구현**.
- 라이브러리 이식·구조화는 팀 작업, 그 안에서 위 두 파트가 내 몫.
- ⚠️ 코드 담주 확인 후 보강 (gis_misc.md 체크리스트 참고): ConvexHull 손댄 범위, 구현한 ST_ 함수 실제 목록, 라이브러리 이름/구조.
